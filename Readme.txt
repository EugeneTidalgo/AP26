ANLEITUNG

1. Öffnen Sie die Datei "index.html" in einem Webbrowser.
   Empfohlene Browser:
   - Google Chrome
   - Mozilla Firefox
   - Microsoft Edge

2. Nach dem Öffnen der Seite klicken Sie oben rechts auf den
   Login-Button, um die Mitglieder-Inhalte anzuzeigen.
   Anschließend öffnet sich ein Pop-up mit dem Login-Menü.

ZUGANGSDATEN
Benutzername: Mitglied
Passwort: lecker

HINWEISE
- Bei falscher Passworteingabe wird eine rote Fehlermeldung angezeigt.
- Sollte das Login-Pop-up nach erfolgreicher Anmeldung weiterhin
  sichtbar bleiben, aktualisieren Sie bitte den Browser (Seite neu laden).
- Sollten die Mitglieder-Inhalte nach erfolgreicher Anmeldung
  nicht angezeigt werden, aktualisieren Sie bitte den Browser (Seite neu laden).
- Benutzername und Passwort sind CASE SENSITIVE (Groß- und Kleinschreibung beachten).
